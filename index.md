### [Introduction to Pure Plane Geometry](https://rozen-f.github.io/ItPG.pdf)

Click the link above to access the full book. Please note that the book is not yet fully completed — the link provides the sections that have already been finished; however, it already includes all of the fundamental content.

The table of contents might look a bit off because, when exporting the PDF from LaTeX, some unnecessary entries were accidentally included due to cached compilation files. Recompiling everything from scratch would’ve been too much trouble, so I manually adjusted a few things directly in the PDF. As a result, the formatting of the contents page isn’t perfect—but it doesn’t affect readability at all.
